# okinawa-itfes-counter

沖縄ビジネスITフェスの受付カウンターを、Windows・Apple・Android の3プラットフォームで作るためのリポジトリ。

実装は下の依頼文に従う。途中で質問せず、迷った点は自分で決めて Pull Request の説明に書く。動作確認の録画を PR に添付する。

各PRは担当フォルダの中だけを変更する。リポジトリ直下のファイル（README.md など）は作らない・変えない。.gitignore などが必要なら各フォルダ内に置く。

## 共通仕様

- アプリ名は「沖縄ビジネスITフェス受付カウンター」
- 画面に来場者数と、定員50席に対する割合（%）を表示する
- 「来場者+1」を押すたびに1人増える
- 50人を超えたら、割合の横に赤字で「定員オーバー」と表示する
- 「リセット」で0人に戻す
- 「来場者+1」を5回押し、表示が「5人・10%」になることを確かめる

## 配置

| フォルダ | 対象 |
| --- | --- |
| `windows/` | Windows・WPF（.NET） |
| `apple/` | macOS / iPhone・SwiftUI |
| `android/` | Android・Kotlin / Jetpack Compose |

## 依頼文①（Windows・WPF）

リポジトリ okinawa-itfes-counter の windows/ フォルダに、WPF（.NET）で受付カウンターアプリを作ってください。

（仕様）アプリ名は「沖縄ビジネスITフェス受付カウンター」。画面に来場者数と、定員50席に対する割合（%）を表示する。「来場者+1」ボタンを押すたびに1人増える。50人を超えたら、割合の横に赤字で「定員オーバー」と表示する。「リセット」ボタンで0人に戻す。作ったらビルドして起動し、「来場者+1」ボタンを実際に5回押して、表示が「5人・10%」になることを確かめてください。その操作の様子を録画してください。終わったら、録画を添えてPRを出してください。途中で私に質問せず、迷ったところは自分で決めて、PRの説明に書いてください。windows/ フォルダの外のファイルは作らず、変えないでください。
