# okinawa-itfes-counter

沖縄ビジネスITフェスの受付カウンターを、Windows・Apple・Android の3プラットフォームで作るためのリポジトリ。

実装は下の依頼文に従う。途中で質問せず、迷った点は自分で決めて Pull Request の説明に書く。動作確認の録画を PR に添付する。

各PRは担当フォルダの中だけを変更する。リポジトリ直下のファイル（README.md など）は作らない・変えない。.gitignore などが必要なら各フォルダ内に置く。

## 共通仕様

- アプリ名は「沖縄ビジネスITフェス受付カウンター」
- 画面に来場者数と、定員50席に対する割合（%）を表示する
- 「来場者+1」を押すたびに1人増える
- 50人を超えたら、割合の横に赤字で「定員オーバー」と表示する
- 「リセット」で0人に戻す
- 「来場者+1」を5回押し、表示が「5人・10%」になることを確かめる

## 見た目

- 沖縄の海をイメージした、濃い青からエメラルドへのグラデーション背景
- 中央に角丸で影のある白いカード。来場者数は画面でいちばん大きな太字
- 割合は数字に加えてプログレスバー（またはリング）でも表示。通常は緑、40人以上はオレンジ、50人超は赤
- 「来場者+1」は大きく目立つ塗りボタン、「リセット」は控えめな枠線ボタン
- 数字が変わるときに軽いアニメーション
- 外部ライブラリ・画像・フォントは使わず、標準機能だけで作る
- 表示の文言（「5人」「10%」「定員オーバー」）は変えない
