# 沖縄ビジネスITフェス受付カウンター（Windows）

Windows用WPFアプリです。Windowsと.NET 8 SDK（デスクトップ開発対応）が必要です。

```powershell
dotnet build windows/ReceptionCounter.csproj -c Release
dotnet run --project windows/ReceptionCounter.csproj -c Release --no-build
```

- 起動時は `0人・0%`。来場者+1で1人ずつ増加します。
- 割合は来場者数 ÷ 50 × 100。50人では100%、51人では102%と赤字の「定員オーバー」を表示します。
- リセットは確認ダイアログなしで0人へ戻し、警告も消します。
- 人数はメモリ内のみで管理し、アプリ終了後には保存しません。
- 上限到達後も加算可能で、割合を100%に丸めません。

## 手動確認

1. 起動して `0人・0%` と警告なしを確認。
2. 「来場者+1」を5回クリックし、`5人・10%` を確認。
3. 50人で `50人・100%` と警告なし、51人で `51人・102%` と赤字警告を確認。
4. リセットで `0人・0%` と警告なしに戻ることを確認。

ビルド成果物はこのフォルダ内の `bin/`、`obj/` に出力されます。録画などのローカル証跡は `artifacts/` に置き、コミットしません。
